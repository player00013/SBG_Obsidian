# セーブ画面（SaveScene）企画・デザイナー向け仕様

## 1. 概要

| 項目 | 内容 |
|---|---|
| 画面名 | セーブ画面（`SaveScene`） |
| 目的 | プレイヤーがセーブスロットを選んで、現在のゲーム状態を保存する |
| 呼び出し元 | ホーム画面の「セーブ」ボタン |
| 戻り先 | ホーム画面 |

ホーム画面の上に重ねて表示される。  
ホーム画面自体は閉じずに、その上にセーブ画面が乗るイメージ。

---

## 2. 画面構成

| 要素 | 内容 |
|---|---|
| タイトル | 左上に「SAVE」と表示 |
| セーブスロット一覧 | 画面中央。縦に並んだスロットをスクロールして選ぶ |
| 戻るボタン | 左下。タップでホーム画面に戻る |
| スクロールバー | 右端に常に表示 |

### 2.1 スロット一覧のイメージ

```
┌─────────────────────────┐
│ AUTO SAVE               │  ← 選択不可
├─────────────────────────┤
│ SAVE01  データあり      │  ← タップで上書き確認
├─────────────────────────┤
│ SAVE02  空              │  ← タップで即保存
├─────────────────────────┤
│ SAVE03  データあり      │
├─────────────────────────┤
│ SAVE04  空              │
│ ...                     │
│ SAVE10  空              │
└─────────────────────────┘
```

---

## 3. スロットの種類

### 3.1 オートセーブスロット

| 項目 | 内容 |
|---|---|
| 表示名 | `AUTO SAVE` |
| 位置 | 一番上 |
| 選択 | できない（見るだけ） |
| 用途 | ゲーム進行で自動保存されるデータの表示 |

### 3.2 任意セーブスロット

| 項目 | 内容 |
|---|---|
| 表示名 | `SAVE01` 〜 `SAVE10` |
| 位置 | オートセーブの下 |
| 選択 | できる |
| 用途 | プレイヤーが自由に保存する |

---

## 4. スロットに表示する情報

データがあるスロットには以下を表示する。

| 項目 | 例 |
|---|---|
| スロット名 | `SAVE03` |
| 保存日付 | `2026/09/13` |
| 保存時刻 | `14:35` |
| プレイ時間 | `36:00`（総時間） |
| チャプター | `3` |
| ハートゲージ | 7 つのアイコン |

空のスロットは、スロット名だけ表示して選択可能な状態にする。

---

## 5. タップしたときの挙動

### 5.1 オートセーブスロット

- 何も起きない

### 5.2 空の任意セーブスロット

1. SE（決定音）を鳴らす
2. そのスロットに保存する
3. スロット一覧を更新する

### 5.3 データがある任意セーブスロット

1. SE（決定音）を鳴らす
2. 上書き確認ポップアップを表示する

#### 上書き確認ポップアップ

| 項目 | 内容 |
|---|---|
| メッセージ | セーブデータを上書きしますか？ |
| 警告文 | ※上書きされるデータは消えてしまいます。 |
| ボタン | いいえ / はい |
| 初期選択 | いいえ |

- **いいえ**：ポップアップを閉じてセーブ画面に戻る
- **はい**：上書き保存して、スロット一覧を更新する

保存完了後は特にポップアップを出さない。

---

## 6. 戻るボタン

| 項目 | 内容 |
|---|---|
| 位置 | 画面左下 |
| 見た目 | 丸い白いボタンに黒い U ターン矢印 |
| タップ時 | ホーム画面に戻る |

---

## 7. サウンド

| 項目 | 内容 |
|---|---|
| BGM | ホーム画面の BGM をそのまま流す |
| 決定音 | スロット選択時、戻るボタン、確認ポップアップのボタン |

---

## 8. 演出

- 画面切り替えはフェードなしですぐに行う
- ホバー時の見た目変化はなし
- ポップアップ表示時は、背後のセーブ画面を操作できなくする

---

## 9. 保留事項

- 実際のセーブデータの中身はまだ決まっていないため、保存処理の詳細は後日詰める
