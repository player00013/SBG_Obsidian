# スタート画面 プランナー向け概要

## 1. この画面は何？

| 項目 | 内容 |
|---|---|
| 画面名 | スタート画面（StartScene） |
| 表示タイミング | ゲーム起動直後 |
| 役割 | タイトルロゴとメニューを表示し、ゲーム開始・終了・設定を受け付ける |

`SystemScene` という裏側の管理シーンと組み合わせて動作する。  
スタート画面は「見た目と操作」を担当し、シーンの読み込みやサウンド管理は `SystemScene` に任せる。

---

## 2. 画面構成

### 2.1 配置

| 要素 | 配置 | 備考 |
|---|---|---|
| タイトルロゴ | 画面上部中央 | `TitleLogo` 画像を表示 |
| メニューボタン | 中央から下へ縦に並べる | 4 つのボタン |
| バージョン表記 | 右上 | `Application.version` の値をそのまま表示 |
| 背景 | 全面 | ピンク色の単色パネル |

### 2.2 色

| 用途 | 色 |
|---|---|
| 背景 | `#FFF0F5`（薄いピンク） |
| 選択中の文字・下線 | `#C71585`（濃いピンク） |

### 2.3 使用素材

| 用途 | 素材名 | 状態 |
|---|---|---|
| タイトルロゴ | `TitleLogo` | ✅ 決定 |
| ボタン背景 / フレーム | `ButtonFrame` | ✅ 決定 |
| フォント | `MainFont` | ✅ 決定 |

### 2.4 Canvas

| 項目 | 設定値 |
|---|---|
| 基準解像度 | `1920×1080` |
| 表示モード | `Expand` |

`Expand` にすることで、16:9 以外の画面でも UI が切れたり引き伸ばされたりせず、黒帯付きで全体が表示される。

## 3. メニューボタン

| 順番 | ボタン名 | 選択時の動作 |
|---|---|---|
| 1 | 始めから | 新規ゲームを開始し、ホーム画面へ遷移 |
| 2 | 続きから | ロード画面へ遷移 |
| 3 | ゲーム終了 | 終了確認ポップアップを表示 |
| 4 | 環境設定 | 環境設定ポップアップを表示 |

### 3.1 「続きから」の有効 / 無効

- セーブデータがある場合：有効
- セーブデータがない場合：無効（グレー表示）
- 無効時は選択できず、ホバーしても反応しない

### 3.2 ボタンの見た目

| 状態 | 文字色 | 下線 |
|---|---|---|
| 標準 | 白 | なし |
| 選択中 | 濃いピンク | あり（画面幅の半分程度） |
| 無効化 | グレー | なし |

- マウスカーソルをボタン上に乗せると、選択状態になる
- キーボード / コントローラーで上下に移動して選択
- 選択が切り替わると、下線は即座に移動する（アニメーションなし）
- 上下の端でさらに同じ方向を押しても、選択はループしない

## 4. 入力・操作

### 4.1 対応デバイス

- マウス
- キーボード
- ゲームコントローラー
- タッチパネル

### 4.2 キーボード操作

| 操作 | キー |
|---|---|
| 上に移動 | `W` / `↑` |
| 下に移動 | `S` / `↓` |
| 決定 | スペース / Enter |
| キャンセル | Esc |

### 4.3 コントローラー操作

| 操作 | ボタン |
|---|---|
| 上に移動 | 十字キー上 / 左スティック上 |
| 下に移動 | 十字キー下 / 左スティック下 |
| 決定 | A ボタン |
| キャンセル | B ボタン |

### 4.4 マウスカーソルの表示

| 操作デバイス | カーソル表示 |
|---|---|
| マウス | 表示 |
| キーボード | 非表示（マウスを動かすと再表示） |
| コントローラー | 非表示（マウスを動かすと再表示） |

### 4.5 初期選択

| 状況 | 最初に選択されるボタン |
|---|---|
| セーブデータなし | 始めから |
| セーブデータあり | 続きから |

### 4.6 Cancel（キャンセル）の扱い

- ポップアップが表示されていない状態で Cancel を押すと、ゲーム終了確認ポップアップが表示される
- ポップアップ表示中は、各ポップアップの Cancel 扱いに従う

## 5. ポップアップ

### 5.1 ゲーム終了確認ポップアップ

| 項目 | 内容 |
|---|---|
| メッセージ | ゲームを終了しますか？ |
| 背景色 | 白 |
| 左ボタン | いいえ（閉じる） |
| 右ボタン | はい（ゲームを終了する） |

- 初期選択は「いいえ」
- Cancel ボタン（Esc / B ボタン）を押すと「いいえ」と同じ扱いで閉じる

### 5.2 環境設定ポップアップ

`StartScene` 専用のポップアップ。別シーンには遷移しない。

#### 表示項目

| 項目 | 操作形式 | 選択肢 / 範囲 |
|---|---|---|
| BGM 音量 | スライダー | 0 〜 1 |
| SE 音量 | スライダー | 0 〜 1 |
| VOICE 音量 | スライダー | 0 〜 1 |
| 画面モード | ドロップダウン | フルスクリーン / ウィンドウ |
| 画面解像度 | ドロップダウン | HD（1280×720） / FHD（1920×1080） |

- マスター音量はなし
- スライダーには数値表示を入れない
- スライダー操作中のリアルタイムプレビューはなし

#### デフォルト値

| 項目 | デフォルト値 |
|---|---|
| BGM 音量 | 0.5 |
| SE 音量 | 0.5 |
| VOICE 音量 | 0.5 |
| 画面モード | ウィンドウ |
| 画面解像度 | FHD（1920×1080） |

#### ボタン配置

| ボタン | 配置 | 動作 |
|---|---|---|
| 閉じる（×） | 右上 | ポップアップを閉じる |
| デフォルトに戻す | 下側左 | 設定をデフォルト値に戻す |
| OK | 下側右 | 設定を反映して閉じる |

#### 反映タイミング

- **OK ボタンを押した時**にまとめて反映
- 閉じるボタン（×）または Cancel を押した場合、変更は破棄される
- ただし、何か UI を操作した後に閉じようとすると、「変更をキャンセルしますか？」の確認ポップアップが表示される

#### デフォルトに戻す確認

- 「デフォルトに戻す」ボタンを押すと、「デフォルトに戻しますか？」の確認ポップアップが表示される
- 初期選択は「いいえ」
- Cancel で閉じる扱い

#### 閉じた後

- スタート画面の「環境設定」ボタンに選択を戻す

## 9. 補足・注意点

- レイアウトの具体的な数値（ロゴサイズ、ボタン間隔、フォントサイズなど）は Unity Editor 上で調整する
- タッチ操作時はホバーによる選択状態の更新は行われず、タップで決定する
- PC スタンドアローン想定。Unity Editor 上ではゲーム終了が無効なので、動作確認時はログ出力で対応する
