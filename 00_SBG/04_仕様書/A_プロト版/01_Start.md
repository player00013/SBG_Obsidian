# スタート画面（StartScene）仕様書

## 1. 概要

| 項目 | 内容 |
|---|---|
| シーン名 | `StartScene` |
| 役割 | ゲーム起動直後のタイトル画面 |
| 読み込み方法 | `SystemScene` から追加読み込み（Additive） |

## 2. シーン構成

| シーン名          | 役割                                                  |
| ------------- | --------------------------------------------------- |
| `SystemScene` | 裏側の管理用シーン。BGM / SE 管理、シーンの読み込み・遷移・解放、汎用ポップアップの管理を担当 |
| `StartScene`  | タイトル画面の表示・操作を担当                                     |

`SystemScene` 内の `SceneController` を経由してシーン遷移を行う。  
`SystemScene` 内の `PopupManager` を経由して汎用メッセージポップアップを表示する。  
`StartScene` は遷移先のシーン名を `SceneController.TransitionTo("シーン名")` で要求し、実際の読み込み・解放は `SceneController` が実行する。

### 2.1 シーン遷移方式

`StartScene` から `HomeScene` / `LoadScene` へ遷移する際は、以下の手順で行う。

1. `SceneController.TransitionTo("HomeScene")` または `TransitionTo("LoadScene")` を呼び出す。
2. `SceneController` が遷移先シーンを Additive で読み込む。
3. 遷移先シーンをアクティブシーンに設定する。
4. `StartScene` をアンロードする。

シーン遷移時の演出は行わない。

## 3. 画面レイアウト

| 要素 | 配置 |
|---|---|
| タイトルロゴ | 画面上部中央。`TitleLogo` 画像を表示する |
| メニューボタン | 中央から下方向へ縦に並べる |
| バージョン表記 | 右上。`Application.version` の値をそのまま表示する |
| 背景 | ピンク色の単色パネル（Image / Panel） |

### 3.1 Canvas 設定

| 項目 | 設定値 |
|---|---|
| Reference Resolution | `1920×1080` |
| Match Mode | `Expand` |

`Expand` を使用することで、画面アスペクト比が `16:9` と異なる場合でも UI が引き伸ばされたり切れたりせず、黒帯を伴って全体が表示される。

### 3.2 色指定

| 用途 | 色 |
|---|---|
| 背景 | `#FFF0F5`（ラベンダーブラッシュ） |
| 選択中文字 / 下線 | `#C71585`（ミディアムヴィオレットレッド） |

### 3.3 タイトルロゴ

- `TitleLogo` 画像を表示する
- アニメーションは入れない

### 3.4 レイアウト数値

以下のレイアウト数値は Unity Editor 上で実際の画面を見ながら調整する。本仕様書では原則として数値を固定しない。

- タイトルロゴの位置・サイズ
- メニューボタンの位置・サイズ
- ボタン同士の間隔
- 選択中下線の長さ
- バージョン表記のフォントサイズ
- ボタンのフォントサイズ

### 3.5 フォント

- テキスト表示には `MainFont` フォントアセットを使用する

## 4. メニューボタン

| 順番 | ボタン名 | 動作 |
|---|---|---|
| 1 | 始めから | `SceneController.TransitionTo("HomeScene")` を呼び出す |
| 2 | 続きから | `SceneController.TransitionTo("LoadScene")` を呼び出す |
| 3 | ゲーム終了 | 終了確認ポップアップを表示 |
| 4 | 環境設定 | 環境設定ポップアップを表示 |

### 4.1 セーブデータについて

- セーブデータは複数スロットで管理する
- 「始めから」を選択すると、`SaveManager.InitializeAutoSave()` を呼び出してオートセーブ用スロットを新規ゲームの状態で初期化し、`HomeScene` へ遷移する
- オートセーブ用スロットに既存データがあっても、そのまま上書きされる
- 「続きから」を選択すると、`LoadScene` へ遷移し、セーブデータの選択を行う
- 任意セーブの詳細や読み込み動作については `02_LoadScene.md` を参照

### 4.2 セーブデータ管理

`SaveManager` の詳細な仕様（スロット数、オートセーブスロットの詳細、読み込みメソッドなど）は `SaveManager.md` にて定義する。  
`StartScene` では以下の点のみ前提とする。

| 項目 | 前提 |
|---|---|
| スロット数 | 複数スロットを持つ |
| オートセーブスロット | 専用のオートセーブスロットが存在する |
| セーブデータ有無判定 | `SaveManager.IsSaveDataExist()` |
| オートセーブの新規ゲーム初期化 | `SaveManager.InitializeAutoSave()` |

## 5. ボタンの見た目

| 状態 | 文字色 |
|---|---|
| 標準 | 白 |
| 選択中 | 濃いピンク（`#C71585`） |
| 無効化 | グレー |

- ボタン背景 / フレーム画像には `ButtonFrame` を使用する
- 選択中のボタンの下に、画面横幅の半分程度の長い下線を表示
- 下線の色は選択中の文字色と同じ濃いピンク
- 「続きから」はセーブデータがない場合、無効化してグレー表示する

### 5.1 選択中下線の動き

- 選択中のボタンが切り替わったとき、下線は即座に移動する
- アニメーションやフェードは行わない
- 下線の位置は、選択中ボタンの下中央に合わせる

### 5.2 マウスホバー時の選択状態

- マウスカーソルがボタン上に乗ったとき、そのボタンを選択状態にする
- キーボードやコントローラーによる選択インデックスと連動する
- ホバー中のボタンは、選択中の見た目（文字色：濃いピンク、下線表示）で表示する

### 5.3 無効化ボタンのホバー扱い

「続きから」が無効化されている場合、以下のように制御する。

- `Button.interactable = false` とする
- マウスホバーしても選択状態にしない
- 下線を表示しない
- `OnClick` イベントを発生させない
- キーボード / コントローラーによる選択移動時も、無効化されたボタンを選択対象から除外する

### 5.4 メニュー選択のループ

- キーボードやコントローラーで選択を移動する際、メニュー選択はループしない
- 一番上のボタンが選択中の状態で「上」を押しても、選択はそのまま
- 一番下のボタンが選択中の状態で「下」を押しても、選択はそのまま

### 5.5 タッチ操作時の扱い

- タッチ操作時はホバーによる選択状態の更新は行われない
- ボタンタップ時は `OnClick` イベントで処理する
- タップ時に一瞬だけホバー状態が発火しても、選択インデックスの更新は行わない

## 6. 入力対応

### 6.1 対応デバイス

- マウス
- キーボード
- ゲームコントローラー
- タッチパネル

### 6.2 入力システム

Unity の **Input System** を使用する。  
Action Map 名や Action 名の詳細は `InputSystem.md` を参照する。

`StartScene` で使用する Action は以下の通り。

| Action 名 | 用途 |
|---|---|
| `Navigate` | 選択項目の上下移動 |
| `Submit` | 決定 |
| `Cancel` | キャンセル |

マウス・タッチ操作は Unity UI の `Button.OnClick` および `EventSystem` のホバー処理を使用する。

### 6.3 キーボード操作

| 操作 | キー |
|---|---|
| 選択を上に移動 | `W` / `↑` |
| 選択を下に移動 | `S` / `↓` |
| 決定 | スペース / Enter |
| キャンセル | Esc |

### 6.4 ゲームコントローラー操作

| 操作 | ボタン |
|---|---|
| 選択を上に移動 | 十字キー上 / 左スティック上 |
| 選択を下に移動 | 十字キー下 / 左スティック下 |
| 決定 | A ボタン |
| キャンセル | B ボタン |

### 6.5 初期選択

| 状況 | 初期選択ボタン |
|---|---|
| セーブデータがない | 始めから |
| セーブデータがある | 続きから |

- セーブデータの有無は `SaveManager.IsSaveDataExist()` で判定
- 「続きから」が無効化されている場合は、自動的に「始めから」にフォーカスを移す

### 6.6 Cancel アクションのタイトル画面での扱い

- ポップアップが表示されていない状態で Cancel アクションを押すと、ゲーム終了確認ポップアップを表示する。
- ポップアップ表示中は、各ポップアップの Cancel 扱いに従う。

### 6.7 マウスカーソル表示

- マウス操作中はカーソルを表示する。
- キーボード操作中はカーソルを非表示にする。
- コントローラー操作中はカーソルを非表示にする。
- マウスを動かしたらカーソルを再表示する。
- キーボードまたはコントローラーの入力があったらカーソルを非表示にする。

## 7. 汎用メッセージポップアップ

`StartScene` 以外のシーンでも使用可能な汎用ポップアップ。  
`SystemScene` に常駐する `PopupManager` を経由して表示する。  
ポップアップ本体は `MessagePopup` プレハブとする。

### 7.1 概要

| 項目 | 内容 |
|---|---|
| 用途 | メッセージ表示とボタン選択を行う汎用ポップアップ |
| ボタン数 | 1 個または 2 個を外部から設定可能 |
| 使用シーン | ゲーム終了確認、その他の確認 / 通知 |

### 7.2 設定可能項目

| 項目 | 説明 |
|---|---|
| メッセージテキスト | ポップアップに表示する本文 |
| ウィンドウ背景色 | ポップアップウィンドウの背景色 |
| ボタンテキスト | 各ボタンに表示するテキスト |
| ボタンの挙動 | 各ボタン押下時のコールバック |

### 7.3 ボタン配置

- ボタンが 1 個の場合は中央に配置
- ボタンが 2 個の場合は左右に配置
- ボタンのテキストと挙動は呼び出し元で指定する

### 7.4 見た目

- ポップアップ背景には半透明の黒いオーバーレイを表示する
- ポップアップの表示・非表示はアニメーションを行わない

### 7.5 オーバーレイクリック時の挙動

- オーバーレイ部分をクリックしてもポップアップは閉じない
- 閉じる操作はボタン選択、Cancel アクション、または × ボタンのみとする

## 8. ゲーム終了ポップアップ

汎用メッセージポップアップを使用する。

### 8.1 内容

| 項目 | 設定値 |
|---|---|
| メッセージ | ゲームを終了しますか？ |
| ウィンドウ背景色 | 白 |
| 左ボタン | いいえ（ポップアップを閉じる） |
| 右ボタン | はい（アプリケーションを終了する） |

### 8.2 ボタン配置

- ボタンは左右に「いいえ / はい」の順で配置する

### 8.3 初期選択

- 初期選択は「いいえ」とする（誤決定防止）

### 8.4 Cancel アクション

- Esc / B ボタンなどの Cancel アクションで、「いいえ」と同じ扱いとしてポップアップを閉じる

### 8.5 終了処理

- 「はい」ボタン押下時は `Application.Quit()` を呼び出してアプリケーションを終了する。
- 本ゲームは PC スタンドアローンを想定しており、Editor や WebGL などのプラットフォーム別の終了処理は別途検討しない。
- Unity Editor 上では `Application.Quit()` が無効なため、動作確認時はログ出力等で対応する。

## 9. 環境設定ポップアップ

`StartScene` 専用のポップアップ。汎用メッセージポップアップとは別物。

### 9.1 表示方法

- `StartScene` 内の UI パネルとして配置する
- Active / Inactive の切り替えで表示・非表示を制御する
- 別シーンへの遷移は行わない

### 9.2 表示内容

| 項目 | 操作形式 | 設定値 |
|---|---|---|
| BGM 音量 | スライダー | 0 〜 1（数値は非表示） |
| SE 音量 | スライダー | 0 〜 1（数値は非表示） |
| VOICE 音量 | スライダー | 0 〜 1（数値は非表示） |
| 画面モード | ドロップダウン | フルスクリーン / ウィンドウ |
| 画面解像度 | ドロップダウン | HD（`1280×720`） / FHD（`1920×1080`） |

- マスター音量は設けない

### 9.3 デフォルト値

| 項目 | デフォルト値 |
|---|---|
| BGM 音量 | `0.5` |
| SE 音量 | `0.5` |
| VOICE 音量 | `0.5` |
| 画面モード | ウィンドウ |
| 画面解像度 | FHD（`1920×1080`） |

### 9.4 ボタン配置

| ボタン | 配置 | 動作 |
|---|---|---|
| 閉じる（×） | 右上 | ポップアップを閉じる |
| デフォルトに戻す | 下側左 | 各設定をデフォルト値に戻す |
| OK | 下側右 | 設定を反映してポップアップを閉じる |

### 9.5 閉じ方

- 右上の × ボタンをクリックする
- Esc / B ボタンなどの Cancel アクションを押す

### 9.6 閉じた後の選択状態

- タイトル画面の「環境設定」ボタンに選択を戻す

### 9.7 見た目

- ウィンドウ背景は白
- ポップアップ背景には半透明の黒いオーバーレイを表示する
- ポップアップの表示・非表示はアニメーションを行わない

### 9.8 反映タイミング

- 各項目の変更は、**OK ボタン押下時にまとめて反映する**
- 音量、画面モード、画面解像度のすべてが OK ボタンで反映される
- 閉じるボタン（×）を押した場合、変更内容は破棄される
- スライダー操作中のリアルタイムプレビューは行わない

### 9.9 保存

- 設定値の保存処理は `SaveManager` に任せる

### 9.10 変更破棄確認ポップアップ

- 環境設定ポップアップでユーザーがいずれかの UI を操作したことがある状態で、× ボタンまたは Cancel アクションを押した場合、変更破棄確認ポップアップを表示する。
- 操作した後に値を元に戻していても、変更ありとみなす。
- 確認ポップアップのメッセージは「変更をキャンセルしますか？」とする。
- 左ボタン：「いいえ」（確認ポップアップを閉じ、環境設定ポップアップに戻る）
- 右ボタン：「はい」（環境設定ポップアップを閉じ、変更を破棄する）
- 初期選択は「いいえ」とする。
- Cancel アクションで「いいえ」と同じ扱いとする。

### 9.11 デフォルトに戻す確認ポップアップ

- 環境設定ポップアップで「デフォルトに戻す」ボタンを押した場合、確認ポップアップを表示する。
- 確認ポップアップのメッセージは「デフォルトに戻しますか？」とする。
- 左ボタン：「いいえ」（確認ポップアップを閉じ、環境設定ポップアップに戻る）
- 右ボタン：「はい」（設定をデフォルト値に戻す）
- 初期選択は「いいえ」とする。
- Cancel アクションで「いいえ」と同じ扱いとする。

## 10. サウンド

### 10.1 BGM

- スタート画面表示開始時から BGM を再生する
- BGM ファイル名は `BGM_Start`

### 10.2 SE

| タイミング | SE |
|---|---|
| ボタン決定時 | `SE_Click` |
| カーソル移動時 | なし |
| キャンセル時 | なし |
| マウスホバー時 | なし |
| 環境設定ポップアップ内のスライダー / ドロップダウン操作時 | なし |

## 11. シーン遷移演出

- シーン遷移時の演出は行わない
- ボタン決定後、`SceneController.TransitionTo("シーン名")` を呼び出し、即座に次のシーンへ切り替える
