# 防衛戦トップ画面（DefenseMenuScene）企画確認用

## 1. 概要

| 項目 | 内容 |
|---|---|
| シーン名 | `DefenseMenuScene` |
| 役割 | `SelectScene` の右側「防衛戦」から遷移し、防衛戦のゲート選択とゲート探索能力強化への入口を提供するトップ画面 |
| 読み込み方式 | `SystemScene` 上に Additive で読み込む |
| 生存期間 | 他シーンへ遷移する際にアンロードする |

## 2. 画面構成

| 位置 | 要素 | 機能 |
|---|---|---|
| 左上 | 戻るボタン | `SelectScene` へ戻る |
| 上部 | タイトル | 「防衛戦」と表示 |
| 左側 | ゲート探索能力強化ボタン | `GatePowerUpScene` へ遷移 |
| 右側 | ゲート一覧 | 防衛戦に使用するゲートを選択する |

## 3. 各要素の詳細

### 3.1 タイトルバー

- 左上に戻るボタンを配置する。
- ボタンには戻るアイコンと「防衛戦」のテキストを表示する。
- タップで `SelectScene` に戻る。

### 3.2 ゲート探索能力強化ボタン

- 画面左側に大きなボタンを配置する。
- ボタンには以下を表示する。
    - 背景画像
    - 中央：人型＋矢印のアイコン
    - 中央下部：「ゲート 探索能力強化」のテキスト
    - 下部：白い再生マーク
- タップで `GatePowerUpScene` へ遷移する。

### 3.3 ゲート一覧

- 画面右側に縦にゲート項目を並べる。
- ゲート数が画面に収まらない場合はスクロール可能にする。
- ゲート項目は台形／平行四辺形の形状とする。
- 未選択の項目はグレー系、選択中の項目は紫系の背景色にする。
- 選択中のゲート項目はハイライト表示し、左側にピンマーカーを表示する。
- 各ゲート項目には必ずドロップアイテムアイコンを表示する。

### 3.4 ゲート項目のレイアウト

各ゲート項目内は以下のように配置する。

| 要素 | 位置 | 備考 |
|---|---|---|
| ピンマーカー | 左側 | 選択中のみ表示。ピン型の形状 |
| ゲート名 | 中央 | 中央寄せで表示 |
| ドロップアイコン | 右側 | `DropItemType` に応じたアイコン |
| 「DROP」テキスト | ドロップアイコンの下 | ピンク／マゼンタ系の固定色 |

### 3.5 ゲート項目のタップ挙動

- ピンマーカーが表示されているゲート項目をタップすると、そのゲートで `PartyEditScene` へ遷移する。
- ピンマーカーが表示されていないゲート項目をタップすると、そのゲートを選択状態にする。
- ピンマーカー自体をタップした場合は、選択されているゲート項目をタップした時と同じ扱いとする。

### 3.6 選択切り替え時のスクロール

- 選択状態に切り替わる際、ゲート一覧をスクロールして選択中ゲートが画面のY軸中心に来るようにする。
- ただし、スクロール可能範囲の上限・下限により中心に来られない場合は、可能な限り中心に近づけてピンマーカーを表示する。
- 先頭のゲートを選択する場合は下側にスクロールできる上限で、他のゲートよりも上側にピンマーカーが表示される。
- 最後尾のゲートを選択する場合は上側にスクロールできる上限で、他のゲートよりも下側にピンマーカーが表示される。

## 4. データ連携

### 4.1 表示に必要なデータ

| フィールド名 | 内容 |
|---|---|
| ゲートID | ゲートの識別子 |
| ゲート名 | ゲート一覧に表示する名前 |
| ドロップタイプ | Mauve / Lime / Agate / Cyan のいずれか |
| 初期選択状態 | 起動時に選択状態にするかどうか |

### 4.2 ドロップアイテム種別

各ゲート項目には必ずいずれかのドロップアイテムが表示される。

| 種別名 |
|---|
| Mauve |
| Lime |
| Agate |
| Cyan |

## 5. 遷移

| 操作 | 遷移先 | 備考 |
|---|---|---|
| 戻るボタン タップ | `SelectScene` | `DefenseMenuScene` をアンロード |
| ゲート探索能力強化ボタン タップ | `GatePowerUpScene` | ゲート探索能力強化画面へ遷移 |
| ピンマーカー付きゲート項目 タップ | `PartyEditScene` | 選択中ゲートで編成画面へ遷移 |

## 6. サウンド

| 項目 | 内容 |
|---|---|
| BGM | `SystemScene` / `AudioManager` で制御するため、`DefenseMenuScene` では制御しない |
| SE | ボタン・ゲート項目タップ時に `SE_Click` を使用 |

## 7. 起動・終了時の挙動

### 7.1 起動

- 想定遷移フロー：`SystemScene` → `StartScene` → `HomeScene` → `SelectScene` → `DefenseMenuScene`
- 読み込み時にデータを読み込み、ゲート項目を生成する。
- 初期選択状態のゲートがあれば、そのゲートを選択状態にする。
- 初期選択がない場合は、先頭のゲートを選択状態にする。
- 選択中ゲートが画面のY軸中心に来るようゲート一覧をスクロールする。

### 7.2 終了

- `SelectScene` へ戻る際、`DefenseMenuScene` をアンロードする。
- `GatePowerUpScene` へ遷移する際も `DefenseMenuScene` をアンロードする。
- `PartyEditScene` へ遷移する際も `DefenseMenuScene` をアンロードする。

## 8. 備考

- `DefenseMenuScene` は `SelectScene` の右側「防衛戦」から遷移する。
- ゲート一覧はスクロール可能にする。
- 各ゲート項目にはドロップアイコンが必ず表示される。
- 背景画像やボタン背景、項目背景色、選択マーカーの色は `DefenseMenuScene` シーン内に埋め込む。
- タブメニューは本画面には配置しない。他機能シーンへの移動は `SelectScene` のタブメニューを経由する。
