# 章選択画面（SelectChapterScene）企画確認用

## 1. 画面の概要

| 項目 | 内容 |
|---|---|
| シーン名 | `SelectChapterScene` |
| 表示タイミング | `SelectScene` の「ストーリー」選択後 |
| 用途 | 章を選んで対応するストーリーシーンへ遷移する |
| 共用 | `Gate`（ゲート）と `Gallery`（回想）で同じシーンを使う |
| 切り替え | `Mode` によって色・背景・タイトル・遷移先を変える |

## 2. 画面レイアウト

| 要素 | 位置 | 役割 |
|---|---|---|
| 戻るボタン | 左上 | `SelectScene`（呼び出し元モード）へ戻る |
| タイトル | 上部 | `Gate` =「章選択」 / `Gallery` =「回想章選択」 |
| 章タイル群 | 中央 | 上下2段にずらして配置。画面内に収まらない想定 |
| ピンマーカー | 中央タイル上 | 最後に選んだ章を示す |

## 3. モード別見た目

| 要素 | Gate | Gallery |
|---|---|---|
| 背景 | 紫系・暗め | 緑系 |
| 解放済みタイル | 紫系 | 緑系 |
| 未解放タイル | グレー系 | グレー系 |
| ピンマーカー | ピンク系 | 緑系 |
| タイトル | 章選択 | 回想章選択 |

## 4. 操作と挙動

| 操作 | 結果 |
|---|---|
| 中央以外のタイルをタップ | タイル全体がスクロールし、タップしたタイルが中央へ移動 |
| 中央のタイルをタップ | その章を選択し、ストーリーシーンへ遷移 |
| ピンマーカーをタップ | その章を選択し、ストーリーシーンへ遷移 |
| 戻るボタンをタップ | `SelectScene` へ戻る |

- スクロール中はタップ不可
- スクロールはアニメーション（即切り替えではない）
- 未解放タイルはタップ不可

## 5. ピンマーカーについて

- **Gate / Gallery 共通：最後に選んだ章**
- 起動時は、最後に選んだ章が中央に表示される
- 章を選んで遷移したら、その章を保存する

## 6. 遷移先

| モード | 遷移先シーン |
|---|---|
| Gate | `StoryProgressionScene` |
| Gallery | `StoryGalleryScene` |

## 7. サウンド

| 種別 | 内容 |
|---|---|
| BGM | 本画面では制御しない |
| SE | タイル・ピン・戻るボタンタップ時に `SE_Click` |

## 8. プランナー・デザイナー確認事項

| # | 項目 | 備考 |
|---|---|---|
| 1 | 章タイルの見た目 | 菱形・上下2段配置・奥行き演出 |
| 2 | モード別カラー | Gate = 紫＋ピンク、Gallery = 緑 |
| 3 | 背景画像 | 各モード1枚ずつ |
| 4 | ピンマーカー画像 | マップピン形状、中央に黒い再生マーク |
| 5 | 章番号表記 | 「0章」などのテキスト |
| 6 | 章の解放状態 | セーブデータから取得 |
| 7 | 遷移先シーン名 | 仮名称の正式化 |

## 9. その他

- タブメニューは本画面に配置しない
- Gate / Gallery とも「最後に選んだ章」がピンの基準
