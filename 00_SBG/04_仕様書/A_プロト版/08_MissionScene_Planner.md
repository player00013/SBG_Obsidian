# ミッション画面（MissionScene）設計書（プランナー向け）

## 1. 概要

| 項目 | 内容 |
|---|---|
| 画面名 | ミッション画面（`MissionScene`） |
| 開き方 | ホーム画面の「ミッション」ボタンから開く |
| 閉じ方 | 左上の戻るボタンのみ |
| 表示形式 | ホーム画面の上に重ねて表示。背景タップでは閉じない |
| 演出 | オープン・クローズ時のアニメーションなし |

## 2. 画面構成

### 2.1 レイアウト

| 位置 | 要素 |
|---|---|
| 左上 | 戻るアイコン ＋ 「ミッション」タイトル |
| 左側 | タブボタン（`メイン` / `リミット` / `完了済み`） |
| 右側メインパネル | 選択中タブの内容 |
| 全画面 | 背景オーバーレイ（ホーム画面の操作をブロック） |

### 2.2 タブ切り替え

- 左側のタブボタンで表示を切り替える。
- 選択中のタブはハイライト表示。
- 初期表示は `メイン` タブ。

## 3. メインタブ

### 3.1 表示内容

| 要素 | 説明 |
|---|---|
| タイトル | `進行中メインミッション` |
| ミッション名 | 現在進行中のメインミッション名 |
| フレーバーテキスト | ミッションの雰囲気を伝える短文 |
| 章情報 | `n章 章のタイトル` |
| キャラアイコン | 章ごとに設定されたキャラクター画像 |
| 進むボタン | 現在進めているゲームプレイシーンへ遷移 |

### 3.2 進むボタン

- タップで、ホーム画面の「メインミッション」ボタンと同じ画面へ遷移する。
- ミッション画面は閉じる。
- 遷移先シーン名は現在保留。

## 4. リミットタブ

### 4.1 表示内容

| 要素 | 説明 |
|---|---|
| タイトル | `n章 リミットミッション` |
| ミッションリスト | リミットミッション名、進むボタン、達成状態アイコン |
| 達成数 | 未受取の達成ミッション数を `00/05` 形式で表示 |
| 報酬表示 | 報酬アイコン × 1回の受取あたりの報酬数 |
| 状態ボタン | 「未達成」「受け取る」「受取済み」のいずれかを表示 |

### 4.2 状態ボタンの表示ルール

| 表示 | 条件 |
|---|---|
| **受取済み** | 全てのリミットミッションを達成し、かつ全ての報酬を受け取り済み |
| **受け取る** | 未受取の達成数が `RewardThreshold` 以上 |
| **未達成** | 上記以外（達成数が `RewardThreshold` 未満） |

### 4.3 報酬受取ルール

- 「受け取る」をタップすると、`RewardThreshold` 件分の未受取達成ミッションを消費する。
- 1回の受取で、`RewardAmount` の報酬を獲得する。
- 受取後、残りの達成数が `RewardThreshold` 以上なら、再度「受け取る」ボタンが表示される。

### 4.4 進むボタン

- 各ミッションの「進む」ボタンをタップすると、そのミッションに設定された画面へ遷移する。
- ミッションごとに遷移先は異なる場合がある。
- ミッション画面は閉じる。

## 5. 完了済みタブ

### 5.1 表示内容

| 要素 | 説明 |
|---|---|
| タイトル | `メインクエスト` |
| リスト | 完了済みメインクエスト名の縦スクロールリスト |

## 6. 必要なデータ

### 6.1 章情報

| 項目 | 内容 |
|---|---|
| 章番号 | 現在の章番号 |
| 章タイトル | 章のタイトル |
| キャラアイコン | 章に対応するキャラクター画像のファイルパス |

### 6.2 進行中メインミッション

| 項目 | 内容 |
|---|---|
| ミッション名 | メインミッション名 |
| フレーバーテキスト | 雰囲気を伝える短文 |
| 遷移先シーン名 | 「進む」ボタンタップ時の遷移先（現在保留） |

### 6.3 リミットミッション（章ごと）

| 項目 | 内容 |
|---|---|
| タイトル | リミットタブのタイトル |
| 閾値（RewardThreshold） | 報酬を受け取るために必要な達成数 |
| ミッションリスト | ミッション名・遷移先・達成状態・受取状態 |
| 報酬アイコン | 報酬画像のファイルパス |
| 報酬数（RewardAmount） | 1回の受取で獲得できる報酬の個数 |

### 6.4 完了済みメインクエスト

- 完了済みメインクエスト名のリスト。
- セーブデータから取得する。

## 7. サウンド

| 項目 | 内容 |
|---|---|
| BGM | ミッション画面では制御しない（SystemScene で管理） |
| SE | ボタンタップ時に `SE_Click` |
| ボイス | なし |

## 8. 備考

- ミッション画面はホーム画面の上に重ねて表示する。
- 表示中はホーム画面の操作を受け付けない。
- リミットミッションに期間限定要素はない。
- 達成数は「達成済みかつ未受取」のミッション数をカウントする。
- オープン・クローズ時のアニメーション演出は行わない。
