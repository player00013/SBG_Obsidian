# セーブデータ読み込み画面（LoadScene）仕様書（簡易版）

## 1. 概要

| 項目 | 内容 |
|---|---|
| シーン名 | `LoadScene` |
| 役割 | セーブデータを選択してゲームを再開する画面 |
| 読み込み方法 | `SystemScene` から追加読み込み（Additive） |
| 演出 | フェードなし、即座に切り替え |

## 2. 画面構成

| シーン名 | 役割 |
|---|---|
| `SystemScene` | 管理用シーン。`SceneController` / `AudioManager` / `EventSystem` を提供 |
| `LoadScene` | セーブデータ選択画面の表示・操作を担当 |

- `SystemScene` の `SceneController` を経由して `HomeScene` または `StartScene` へ遷移する。
- `SystemScene` の `EventSystem` を共用する。

## 3. 画面レイアウト

| 要素 | 配置 | 備考 |
|---|---|---|
| タイトル「LOAD」 | 画面左上 | 右側に白い水平線を表示 |
| セーブデータリスト | 画面中央 | 縦に並べたセーブスロット |
| 戻るボタン | 画面左下 | 白い丸ボタンに黒い U ターン矢印アイコン |
| スクロールバー | 画面右端 | ピンク色の縦スクロールバー（常に表示） |
| 背景 | 全面 | ピンク色の単色（`#FFF0F5`）。後から画像に差し替え可能 |

### 3.1 Canvas 設定

| 項目 | 設定値 |
|---|---|
| Reference Resolution | `1920×1080` |
| Match Mode | `Expand`（アスペクト比が異なる場合も黒帯で全体表示） |

### 3.2 色指定（主要部分）

| 用途 | 色 |
|---|---|
| 背景 | `#FFF0F5`（ラベンダーブラッシュ） |
| タイトル「LOAD」 | 白 |
| 戻るボタン | 白 |
| 戻るボタンアイコン | 黒 |
| スロット名 | 白 |
| Date ラベル・日時 | 黒 |
| スクロールバー | ピンク系 |
| 空スロットの六角形 | グレー |
| ハートアイコン（高レベル） | 濃いピンク |
| ハートアイコン（低レベル） | 薄いピンク |
| ハートアイコン（未仲間） | グレー |

## 4. セーブデータの表示

### 4.1 表示するスロット

| 種別 | 数 | 表示名 | 位置 |
|---|---|---|---|
| オートセーブ | 1 | `AUTO SAVE` | 最上部 |
| 任意セーブ | 10 | `SAVE01` 〜 `SAVE10` | オートセーブの下に昇順 |

- 全スロット（11個）を常に表示する。
- データがないスロットも、空スロットとして表示する。

### 4.2 各スロットに表示する情報

| 情報 | 内容 |
|---|---|
| スロット名 | `AUTO SAVE` / `SAVE01` など |
| 保存日時 | `Date` ラベル、日付、時刻（24時間制） |
| ハートゲージ | 7個のアイコンで仲間キャラの数とレベルを表現（暫定） |

- プレイ時間とチャプター名はこの画面では表示しない。

### 4.3 空スロットの扱い

- 六角形ラベルをグレーにする。
- 日時欄を空欄にする。
- ハートゲージを7つすべてグレーにする。
- クリック・タップを受け付けない（選択不可）。

### 4.4 オートセーブが空の場合

- `AUTO SAVE` スロットは通常通り最上部に表示する。
- 空スロットと同じ見た目・選択不可にする。

## 5. 操作・遷移

### 5.1 スロット選択時

1. データがあるスロットをタップ / クリックする。
2. SE（`SE_Click`）を再生する。
3. セーブデータの読み込み処理を行う。
4. ロード成功時に `HomeScene` へ遷移する。

- **現時点はダミーデータのため、すべてのロードを失敗扱いとする。**
- ロード失敗時はデバッグ用のエラーログを出力し、画面はロード画面のままとする。
- ポップアップでのエラー表示は行わない。

### 5.2 戻るボタン

| 項目 | 内容 |
|---|---|
| 位置 | 画面左下 |
| 見た目 | 白い丸ボタンに黒い U ターン矢印アイコン |
| 動作 | `StartScene` へ遷移する |
| ホバー時 | 見た目は変化しない |
| SE | `SE_Click` |

## 6. 入力対応

| 対応デバイス | 操作 |
|---|---|
| マウス | クリック、ホイールスクロール |
| タッチ | タップ、スワイプスクロール |

- キーボード・ゲームコントローラー操作は想定しない。
- スロットへのホバーでは見た目を変えない。

## 7. サウンド・演出

| 項目 | 内容 |
|---|---|
| SE | スロット選択時・戻るボタン時に `SE_Click` |
| シーン遷移 | フェードなしで即座に切り替え |

## 8. 保留事項

| 項目 | 理由 |
|---|---|
| セーブデータ本体の読み込み処理 | `SaveData` 構造が未確定 |
| ハートゲージの正確な表示ルール | セーブデータ構造・ゲームデザイン確認待ち |
