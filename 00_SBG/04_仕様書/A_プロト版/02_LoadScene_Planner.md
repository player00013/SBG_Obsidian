# セーブデータ読み込み画面（LoadScene）機能確認用まとめ

## 1. 画面の目的
- セーブデータを選択してゲームを再開する画面
- `SystemScene` から追加読み込み（Additive）で表示
- `SystemScene` の `SceneController` / `EventSystem` を共用

## 2. 画面レイアウト
| 要素 | 内容 |
|---|---|
| タイトル | 左上に「LOAD」と白い水平線 |
| セーブスロット一覧 | 中央に縦スクロールで表示 |
| 戻るボタン | 左下。白い丸ボタンに黒い U ターン矢印 |
| スクロールバー | 右端に常時表示（Track：薄いピンク / Handle：濃いピンク） |
| 背景 | 単色 `#FFF0F5`（ラベンダーブラッシュ） |

- Canvas：Reference Resolution `1920×1080`、Match Mode `Expand`
- タイトル・スロット間隔などの細かい数値は Unity Editor 上で調整

## 3. セーブスロットの構成
| 種別 | 数 | 表示名 | 位置 |
|---|---|---|---|
| オートセーブ | 1 | `AUTO SAVE` | 一番上 |
| 任意セーブ | 10 | `SAVE01` 〜 `SAVE10` | オートセーブの下に昇順 |

- 全 11 スロットを常に表示
- 空のスロットもグレー表示で選択不可

## 4. スロットに表示する情報
| 項目 | 内容 |
|---|---|
| スロット名 | `AUTO SAVE` / `SAVE01` など |
| 日時 | `Date` ラベル＋`yyyy/MM/dd`＋`HH:mm` |
| プレイ時間 | `PlayTime` ラベル＋`HH:mm` |
| チャプター | `Chapter` ラベル＋番号 |
| ハートゲージ | 7 個のアイコンで仲間／解放状態を表示 |

### ハートゲージの見た目（仮）
| 色 | 意味 |
|---|---|
| 濃いピンク `#FF1493` | 仲間＋エロシーン解放 |
| 薄いピンク `#FFB6C1` | 仲間だが未解放 |
| グレー `#808080` | 仲間になっていない |

## 5. 空スロットの扱い
- 六角形ラベルをグレーに
- スロット名のみ表示
- 日時・プレイ時間・チャプター・ハート情報は非表示
- ハートゲージは 7 つすべてグレー
- `Button.interactable = false` で選択不可

## 6. 入力対応
- 対応デバイス：**マウス・タッチのみ**
- 使用 Action：`Point`（カーソル位置）、`Click`（クリック／タップ）
- ホバー時の見た目変化なし
- キーボード・コントローラー操作は想定外

## 7. スロット選択時の動作
1. タップ / クリック
2. SE（`SE_Click`）再生
3. ロード処理を実行
4. 成功時：`HomeScene` へ遷移

※現時点では `SaveData` 構造未確定のため、実際のロードは保留。  
　仮実装として「このセーブデータは現在読み込めません。」のポップアップを表示。

## 8. 戻るボタン
- クリックで `StartScene` へ遷移
- `SceneController.TransitionTo("StartScene", "LoadScene")` を呼ぶ
- SE：`SE_Click`
- ホバー時の見た目変化なし

## 9. 表示条件
- 任意セーブデータが 1 件もない場合、`LoadScene` は開かない
- `StartScene` の「続きから」ボタンはセーブデータがない場合無効化

## 10. 演出・SE
| 項目 | 内容 |
|---|---|
| BGM | なし |
| SE | 全ボタン共通 `SE_Click` |
| 画面遷移 | フェードなしで即座に切り替え |
