# シナリオ画面（NovelScene）企画書

## 1. 画面の概要

| 項目 | 内容 |
|---|---|
| シーン名 | `NovelScene` |
| 役割 | ノベルパートのシナリオ再生画面 |
| 読み込み方 | `SystemScene` 上に重ねて表示（Additive） |
| 閉じ方 | 最後のセリフを表示後、「次へ」で元の画面に戻る |

### 1.1 呼び出し元

以下の画面から開かれる。

- `GateStoryScene`（ストーリー進行画面）
- `RouteMapScene`（ルート進行画面）
- `StoryGalleryScene`（回想ストーリー選択画面）

### 1.2 戻り先

呼び出した画面に自動で戻る。`NovelScene` 側で戻り先を指定する必要はない。

---

## 2. 画面構成

| エリア | 内容 |
|---|---|
| 背景 | シナリオの背景画像を全画面表示 |
| キャラクター | 中央に立ち絵を 1〜3 人表示 |
| テキストウィンドウ | 下部に話者名とセリフ本文を表示 |
| コントロールボタン | ウィンドウ右下に配置 |

### 2.1 キャラクター表示

- 立ち絵は全身表示。
- 表示人数は 1〜3人。
  - 1人：中央
  - 2人：左＋右
  - 3人：左＋中央＋右
- 切り替えは即座に行う（アニメーションなし）。
- ファイル名が空欄の位置は非表示。

### 2.2 テキスト表示

- 話者名と本文を表示。
- 話者名が空欄のときは名前欄を非表示。
- 表示方式は設定で切り替え。
  - 一括表示：全文を即表示
  - 文字送り：1文字ずつ表示
- 履歴（バックログ）はなし。

### 2.3 コントロールボタン

| ボタン | 機能 |
|---|---|
| 前へ | 1つ前のセリフに戻る |
| 次へ | 次のセリフに進む / 最後なら元画面に戻る |
| 最後へ | 最後のセリフまで一気に進む |
| UI非表示 | テキストウィンドウとボタンを隠す |
| オプション | 環境設定ポップアップを開く |

---

## 3. 入力操作

| 操作 | 効果 |
|---|---|
| 画面タップ | 次のセリフへ進む |
| 長押し（0.5秒） | 早送り開始 |
| UI非表示中の画面タップ | UI を再表示（セリフは進まない） |
| 各ボタン | ボタンに表記された機能 |

---

## 4. サウンド

| 種別 | 内容 |
|---|---|
| BGM | セリフごとに指定。空欄なら前のBGMを維持 |
| SE | セリフごとに指定。空欄なら鳴らさない |
| ボイス | なし |

---

## 5. 設定項目

`NovelScene` で使用する設定は、既存の環境設定ポップアップと同じ `SaveManager.Settings` で管理する。

| 項目 | 内容 |
|---|---|
| BGM 音量 | 0 〜 1 |
| SE 音量 | 0 〜 1 |
| 文字送りフラグ | ON で文字送り、OFF で一括表示 |
| 文字送り速度 | 1文字あたりの秒数 |
| 早送り速度 | 長押し早送り時の1文字あたり秒数 |

---

## 6. 必要なデータ

### 6.1 シナリオデータ（`NovelSceneData`）

- `ScriptableObject` で作成。
- セリフをリストで保持する。

### 6.2 1件のセリフ（`SerifData`）

| 項目 | 内容 |
|---|---|
| BGM 名 | このセリフで再生するBGMファイル名 |
| SE 名 | このセリフで再生するSEファイル名 |
| 背景画像名 | 背景画像ファイル名 |
| 左キャラ画像名 | 左立ち絵ファイル名 |
| 中央キャラ画像名 | 中央立ち絵ファイル名 |
| 右キャラ画像名 | 右立ち絵ファイル名 |
| 話者名 | セリフの話者 |
| 本文 | セリフの文章 |

---

## 7. リソース配置場所

| 種別 | 配置場所 |
|---|---|
| 背景画像 | `Resources/Novel/Backgrounds/` |
| キャラクター画像 | `Resources/Novel/Characters/` |
| BGM | `Resources/Audio/BGM/` |
| SE | `Resources/Audio/SE/` |

---

## 8. 備考

- シナリオ中のセーブは行わない。
- 画面比率は 16:9 固定。
- 選択肢（分岐）はなし。
- 未読 / 既読の判定はなし。
- 履歴（バックログ）はなし。
- キーボード入力は非対応。
