# ホーム画面（HomeScene）仕様書【プランナー / デザイナー向け】

## 1. 概要

| 項目 | 内容 |
|---|---|
| シーン名 | `HomeScene` |
| 役割 | ゲームの拠点・ハブ画面。キャラクター表示、各種機能への導線、セーブ、ミッション確認など |
| 読み込み方法 | `SystemScene` から追加読み込み（Additive） |

`SystemScene` が裏で管理しており、`HomeScene` は表示と操作を担当する。

---

## 2. 画面レイアウト

### 2.1 配置要素

| 要素 | 配置 | 説明 |
|---|---|---|
| 背景画像 | 画面全体 | `HomeSceneData` で指定された画像を表示 |
| キャラクター立ち絵 | 画面中央 | `HomeCharacterData` で指定された画像を表示 |
| 左右三角矢印 | 画面左右 | キャラクター / 衣服の切り替えボタン |
| `メインミッション` ボタン | 画面左上 | 仮実装。タップで「準備中です」ポップアップ |
| UI 非表示ボタン | 画面右上左側 | UI を非表示にし、キャラ・背景・吹き出しのみ表示 |
| 背景切り替えボタン | 画面右上中央 | 所持背景を順に切り替え。最後はランダム選択 |
| ハンバーガーメニューボタン | 画面右上右側 | メニューオーバーレイを表示 |
| `Tips` 表示エリア | 画面左下 | ゲームのヒントを一定時間ごとにランダム表示 |
| `セーブ` ボタン | 画面右下左側 | セーブ画面を重ねて表示 |
| `ミッション` ボタン | 画面右下右側 | ミッション一覧ポップアップを表示 |
| キャラクター吹き出し | キャラクター右側 | キャラクタータップ時にセリフを表示 |
| 下部タブメニュー | 画面下部 | 各機能シーンへ遷移するタブ |

### 2.2 Canvas 設定

| 項目 | 設定値 |
|---|---|
| Reference Resolution | `1920×1080` |
| Match Mode | `Expand` |

`Expand` を使用することで、16:9 以外の画面でも UI が引き伸ばされたり切れたりせず、黒帯を伴って全体が表示される。

### 2.3 レイアウト数値

以下は Unity Editor 上で実際の画面を見ながら調整する。本仕様書では原則として数値を固定しない。

- キャラクター立ち絵の位置・サイズ
- 左右三角矢印の位置・サイズ
- 各ボタンの位置・サイズ
- `Tips` 表示エリアの位置・サイズ
- 吹き出しの位置・サイズ
- 下部タブメニューの位置・サイズ
- タブボタンの間隔
- メニュー項目ボタンの間隔・フォントサイズ
- メニューラベルの位置・サイズ
- ミッションポップアップのウィンドウサイズ
- ミッションポップアップ内タブサイズ
- ミッションリスト項目の間隔
- スクロールバーの幅

## 3. 入力対応

### 3.1 対応デバイス

- マウス
- タッチパネル

### 3.2 入力システム

- Unity の Input System を使用する。
- マウス・タッチ操作は Unity UI の `Button` クリックおよび `EventSystem` のホバー処理を使用する。

## 4. 各種ボタン・機能

### 4.1 下部タブメニュー

| 順番 | タブ名 | 遷移先シーン |
|---|---|---|
| 1 | ホーム | `HomeScene`（現在のシーン） |
| 2 | キャラクター | `CharacterScene` |
| 3 | 娼館 | `BrothelScene` |
| 4 | ゲート | `GateScene` |
| 5 | 回想 | `ReminiscenceScene` |
| 6 | 武器製造 | `WeaponCraftingScene` |

- 選択中のタブはハイライト表示する。
- タブタップで各シーンへ遷移する。遷移演出はなし。
- 現在 `HomeScene` にいるときに「ホーム」タブをタップしても、何も起きない（SE もなし）。

### 4.2 キャラクター表示と切り替え

- 画面中央にキャラクター立ち絵を表示する。
- 左右の三角矢印をタップすると、キャラクター / 衣服を切り替える。
- 切り替えはループする（最後の次は最初に戻る）。
- 同じキャラクターの衣服違いも含めて、1 つの連続リストとして管理する。
- キャラクター画像が 1 枚以下の場合、左右の三角矢印は表示しない。
- 切り替え時に `SE_Click` を再生する（連打時も毎回再生）。
- キャラクター切り替え時、吹き出しは消える。
- キャラクター切り替え後は、現在のキャラクターインデックスを即座に更新する。

### 4.3 UI 非表示ボタン

- タップすると、以下の UI 要素を非表示にする。
  - 下部タブメニュー
  - `メインミッション` ボタン
  - UI 非表示ボタン自身
  - 背景切り替えボタン
  - ハンバーガーメニューボタン
  - `セーブ` ボタン
  - `ミッション` ボタン
  - 左右三角矢印
  - `Tips` 表示エリア
- 非表示中は背景画像、キャラクター立ち絵、吹き出しのみ表示する。
- 背景画像をタップすると、UI を再表示する。
- キャラクター立ち絵をタップした場合は UI を復帰させず、セリフ表示の処理を行う。
- UI 非表示 / 復帰時に `SE_Click` を再生する。
- ハンバーガーメニューオーバーレイ、ポップアップ、セーブ画面の重ね表示中は UI 非表示ボタンは押せない。

### 4.4 背景切り替えボタン

- タップするたびに表示モードを切り替える。
- 背景が 1 枚しかない場合：
  - 「固定表示モード」と「ランダムモード」をトグル切り替える。
- 背景が 2 枚以上ある場合：
  - 所持背景をインデックス順に切り替える。
  - 最後の背景の次は「ランダム」選択モードに切り替わる。
  - ランダムモード時にタップすると、最初の背景に戻る。
- ランダムモード中は、背景切り替えボタンの見た目をランダムモード用の画像に変更する。
- 背景切り替え時に `SE_Click` を再生する（前後が同じ・連打時も毎回）。
- 背景切り替え後は、現在の背景インデックスとランダムモードフラグを即座に更新する。
- 背景画像リストが空の場合：
  - 背景画像を非表示にし、背景色を `#FFF0F5`（ラベンダーブラッシュ）にする。

### 4.5 ハンバーガーメニュー

- 右上のハンバーガーアイコンボタンをタップすると、メニューオーバーレイを表示する。
- オーバーレイ表示中は、背景を半透明の黒で暗くする。
- オーバーレイ背景は他の UI 操作を受け付けないようにする。
- 左上の戻るボタンのみでメニューを閉じる。
- オーバーレイの暗い背景部分をタップしても閉じない。
- 表示 / 非表示はアニメーションを行わず、即座に切り替える。

#### 4.5.1 メニュー項目

| 項目 | 動作 |
|---|---|
| ゲーム設定 | 「準備中です。」ポップアップを表示 |
| タイトルへ戻る | 確認ポップアップ → 「はい」でタイトル画面へ遷移 |
| アイテム | 「準備中です。」ポップアップを表示 |

- 各メニュー項目の SE は `SE_Click` を使用する。

#### 4.5.2 メニュー項目ボタン

- メニュー項目のボタンは六角形の Sprite `HexagonButton` を使用する。
- ボタンの背景色は白、文字色は黒とする。
- ボタンの当たり判定は四角形のままでよい。
- ボタンは縦一列に並べる。
- ボタン同士の間隔・フォントサイズは Unity Editor 上で調整する。

#### 4.5.3 戻るボタンとメニューラベル

- 左上に丸い戻るボタンを配置する。
- 戻るボタンの背景は黒、アイコンは白とする。
- 戻るボタンの右側に「メニュー」ラベルを表示する。
- メニューラベルの背景はピンク系の角丸パネル、文字色は黒とする。
- タップ時に `SE_Click` を再生する。

#### 4.5.4 タイトルへ戻る確認ポップアップ

| 項目 | 設定値 |
|---|---|
| メッセージ | タイトルに戻りますか？ |
| 警告文 | ※セーブしていないデータは消えてしまいます。（赤文字） |
| ウィンドウ背景色 | `#FFA4F3` |
| 左ボタン | 「いいえ」 / `#7F7F7F` |
| 右ボタン | 「はい」 / `#404040` |
| ボタン文字色 | 白 |

- 「いいえ」が選択された場合、確認ポップアップを閉じてメニューオーバーレイに戻る。
- 「はい」が選択された場合、タイトル画面へ遷移する。

### 4.6 `メインミッション` ボタン

- 画面左上の `メインミッション` ボタンをタップすると、ミッション名に対応した画面に遷移する予定。
- 今回はデータ未整備のため仮実装とする。
- タップ時に「準備中です。」ポップアップを表示する。
- タップ時に `SE_Click` を再生する。

### 4.7 `Tips` 表示エリア

- 画面左下に `Tips` テキストを表示する。
- `Tips` はボタンではなく、表示専用のテキストエリアとする。
- `HomeSceneData.TipsList` にセットされたテキストを、一定時間ごとにランダムで切り替えて表示する。
- テキストは複数行に対応する。
- 切り替え間隔はデフォルトで 30 秒とする。
- 切り替え時のアニメーションは行わず、即座に切り替える。
- `HomeScene` 表示直後、最初の 1 回目は即座にランダム表示する。
- 前回と同じ Tips が選ばれた場合は再抽選する。
- `TipsList` が空の場合、何も表示しない。

### 4.8 `セーブ` ボタン

- 画面右下の `セーブ` ボタンをタップすると、セーブ画面を Additive で重ねて読み込む。
- `HomeScene` はアンロードしない。
- タップ時に `SE_Click` を再生する。

### 4.9 `ミッション` ボタン

- 画面右下の `ミッション` ボタンをタップすると、ミッション一覧ポップアップを表示する。
- ミッション一覧のデータは `HomeMissionData` から取得する。
- ポップアップには `メイン` / `リミット` / `完了済み` の 3 タブを表示する。
- タブ切り替えで表示内容を切り替える。
- ミッションリストはスクロール可能とし、スクロールバーを右側に表示する。
- ポップアップを閉じるのは左上の戻るボタンのみとする。
- 戻るボタンには `IconBack` を使用する。
- タップ時に `SE_Click` を再生する。
- ポップアップを閉じた後の選択状態は特に制御しない。

#### 4.9.1 ミッションポップアップの見た目

- ポップアップウィンドウの背景色は濃いグレー（`#404040`）とする。
- 左側にタブを縦に 3 つ配置する。
- 選択中のタブはピンク（`#FFA4F3`）、非選択のタブはグレー（`#7F7F7F`）とする。
- タブ背景全体の色は濃いグレー（`#404040`）とする。
- メイン / リミット タブの右側コンテンツエリア背景色はピンク（`#FFA4F3`）とする。
- 完了済みタブの右側コンテンツエリア背景色は濃いグレー（`#404040`）とする。

#### 4.9.2 スクロール

- メインタブは 1 つのミッションのみ表示するため、スクロールは不要とする。
- リミットタブと完了済みタブは、リストが画面に収まらない場合にスクロール可能とする。
- スクロールバーは右側に配置する。

#### 4.9.3 メインタブ

- タイトル：「進行中メインミッション」
- ミッション名を表示する。
- フレーバーテキストを複数行で表示する。
- 「進む」ボタンを表示する。
- 章のタイトル：「0章 章のタイトル」を表示する。
- キャラアイコンを表示する。
- 「進む」ボタンをタップすると、メインミッション画面へ遷移する。

#### 4.9.4 リミットタブ

- タイトル：「0章リミットミッション」
- ミッション名のリストを表示する。
- 各ミッションに「進む」ボタンを表示する。
- 「進む」ボタンをタップすると、対応するシーン（キャラクター / 娼館 / ゲート / 回想 / 武器製造）へ遷移する。
- 下部に達成数「0章達成数 00/05」を表示する。
- 報酬アイコンと報酬数を表示する。
- 未達成 / 受け取る ボタンを表示する。
- 「受け取る」ボタンは今回仮実装とし、タップ時に「未実装です」ポップアップを表示する。

#### 4.9.5 完了済みタブ

- 右側コンテンツエリアの背景色は濃いグレー（`#404040`）とする。
- ヘッダー：「メインクエスト」を表示する。
- ヘッダー背景色はピンク（`#FFA4F3`）とする。
- クエスト名のリストを表示する。
- クエスト名は白い角丸パネル状の項目に表示する。

#### 4.9.6 空のミッションリスト

- メインミッションとリミットミッションは必ず存在するため、空の表示は行わない。

### 4.10 吹き出し（キャラクターセリフ）

- キャラクター立ち絵をタップすると、キャラクターのセリフを吹き出しで表示する。
- セリフテキストは `HomeCharacterData.SpeechList` からランダムに選ぶ。
- 吹き出しの表示位置はキャラクター立ち絵の右側固定とする。
- 吹き出しの背景色は薄いグレー、文字色は黒とする。
- 吹き出しの形状は画像通りとする。
- セリフは一定時間表示された後、自動で消える。
- 表示時間はデフォルトで 15 秒とする。
- 吹き出し表示中にキャラクター立ち絵をタップしたら、別のセリフに切り替える。
- 連続タップ時は表示時間をリセットする。
- 左右矢印でキャラクターを切り替えた場合、吹き出しは消える。
- キャラクター切り替え後は自動でセリフを表示せず、プレイヤーのタップを待つ。
- セリフが一定文字数を超える場合、最大文字数まで表示し、それ以上は表示しない。
- 最大文字数はデフォルトで 100 文字とする。
- UI 非表示モード中もキャラクター立ち絵をタップするとセリフを表示する。
- キャラクター立ち絵タップ時に `SE_Click` を再生する。
- キャラクター画像リストが空の場合：
  - キャラクター立ち絵を非表示にする。
  - 左右の三角矢印も非表示にする。
  - セリフ表示は行わない。

## 5. サウンド

### 5.1 BGM

- BGM は `SystemScene` で制御するため、`HomeScene` には BGM 再生機能を持たせない。

### 5.2 SE

| タイミング | SE |
|---|---|
| ボタンタップ時（各種） | `SE_Click` |
| キャラクター切り替え時 | `SE_Click` |
| 背景切り替え時 | `SE_Click` |
| キャラクター立ち絵タップ時 | `SE_Click` |
| UI 非表示 / 復帰時 | `SE_Click` |
| 吹き出し表示時 | `SE_Click` |
