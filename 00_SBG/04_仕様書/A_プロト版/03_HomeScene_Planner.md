# ホーム画面（HomeScene）仕様書（プランナー向け）

## 1. 概要

| 項目 | 内容 |
|---|---|
| シーン名 | `HomeScene` |
| 目的 | ゲームのホーム画面。キャラクター表示、各機能への入口、セーブ・ミッション・設定アクセスを行う |
| 読み込み方式 | `SystemScene` 上に Additive で読み込む |
| 生存期間 | 下部タブで他シーンに遷移する際にアンロードする |

## 2. 画面構成

| エリア | 要素 | 機能 |
|---|---|---|
| 左上 | メインミッション | 現在進めているゲームプレイシーンへ遷移 |
| 右上 | 全画面アイコン | 背景・キャラ・吹き出し以外のUIを非表示にする |
| 右上 | ホーム設定アイコン | 背景を順に切り替える。最後はランダム背景モード |
| 右上 | ハンバーガーメニュー | メニュー画面（`HomeMenuScene`）を開く |
| 中央 | キャラクター立ち絵 | タップで反応。セリフ吹き出しを表示 |
| キャラ右横 | セリフ吹き出し | キャラタップ時に表示。15秒で消える |
| 左右 | 三角ボタン | キャラクター画像を前後に切り替える |
| 左下 | Tips | テキストを5秒ごとにランダム切り替え |
| 右下 | セーブ | セーブ画面（`SaveScene`）を開く |
| 右下 | ミッション | ミッション一覧画面を開く |
| 下部 | タブメニュー | 各機能シーンへ遷移 |

## 3. キャラクター表示

- 中央にキャラクター立ち絵を1体表示する。
- 左右の三角ボタンで表示するキャラクターを切り替える。
- 同じキャラクターでも衣服が違う場合は、別の画像として切り替え対象に含める。
- キャラクター画像はループして切り替える。先頭より前に戻ると末尾、末尾より後に進むと先頭に戻る。
- キャラクターをタップすると、SEが再生され、セリフ吹き出しが表示される。
- 吹き出しが既に表示されている場合は、セリフ内容を更新する。

## 4. 背景表示

- ホーム設定アイコンをタップするたびに、所持している背景を順に切り替える。
- 全ての背景を順に表示し終えると、次はランダム背景モードになる。
- ランダム背景モードでは、所持背景の中からランダムに選んで表示する。
- ランダム背景モードの状態でさらにアイコンをタップすると、先頭の背景から切り替えを再開する。
- ランダム背景モード時は、アイコンがランダム背景アイコンに変わる。

## 5. セリフ吹き出し

- キャラクターをタップすると、キャラクターの右横に吹き出しを表示する。
- 吹き出しのセリフは、あらかじめ設定されたセリフリストからランダムに選ぶ。
- 吹き出しは15秒経過後に自動で消える。
- ボイスは再生しない。

## 6. Tips表示

- 画面左下にTipsテキストを表示する。
- Tipsはあらかじめ設定されたリストからランダムに選ぶ。
- 5秒ごとに別のTipsに切り替える。
- 直前に表示していたTipsと同じ内容は選ばない。
- フェードイン・フェードアウトは行わない。

## 7. ボタン機能

### 7.1 メインミッション
- 現在進めているゲームプレイシーンへ遷移する。

### 7.2 全画面アイコン
- タップすると、背景・キャラ・吹き出し以外のUIを全て非表示にする。
- 背景部分（キャラと吹き出し以外）をタップすると、UIを再表示する。

### 7.3 ホーム設定アイコン
- 背景を順に切り替える。
- 最後はランダム背景モード、さらにタップすると先頭に戻る。

### 7.4 ハンバーガーメニュー
- メニュー画面（`HomeMenuScene`）を開く。
- メニュー画面で設定変更が行われた場合、ホーム画面はその状態を保持する。

### 7.5 セーブ
- セーブ画面（`SaveScene`）を開く。

### 7.6 ミッション
- ミッション一覧画面を開く。
- ミッション一覧には、メインミッション・リミットミッションの一覧と達成状況を表示する。

## 8. タブメニュー

- 下部のタブメニューから各機能シーンへ遷移する。
- タブメニューはPrefab化しており、他のシーンでも同じものを使用する。
- 現在いるシーンのタブはハイライト表示する。
- 同じタブを選んでも何も起きない。

### 8.1 遷移先

| タブ名 | 遷移先シーン |
|---|---|
| ホーム | `HomeScene`（現在地） |
| キャラクター | `CharacterScene` |
| 娼館 | `BrothelScene` |
| ゲート | `GateScene` |
| 回想 | `GalleryScene` |
| 武器製造 | `WeaponCraftingScene` |

### 8.2 遷移時の注意

- タブ選択で他シーンに遷移する際、`HomeScene` はアンロードする。

## 9. サウンド

| 項目 | 内容 |
|---|---|
| BGM | `SystemScene` で制御。`HomeScene` では制御しない |
| SE | 各ボタンタップ・キャラクタータップ時に `SE_Click` を使用 |
| ボイス | なし |

## 10. 起動・終了

### 10.1 起動
- `SystemScene` → `StartScene` → `HomeScene` の順で遷移してくる。
- `HomeScene` 読み込み時に、ホーム画面用データからキャラ・背景・セリフ・Tipsを読み込んで表示する。

### 10.2 終了
- 下部タブで他シーンに遷移する際に `HomeScene` をアンロードする。
- メニュー画面、セーブ画面、ミッション一覧画面を閉じる際は `HomeScene` はアンロードしない。

## 11. 備考

- `HomeScene` はゲーム終了まで常駐しない。他機能シーンから戻ってくる場合は再読み込みする。
- `HomeVisualData` / `HomeVisualSlot` は廃止する。
- 画像読み込みに失敗した場合、エラーログを出力する。フォールバック画像は用意しない。

## 12. 今後検討事項

| 項目 | 内容 |
|---|---|
| 吹き出しの消去時間 | 現状は15秒。後から変更する可能性あり |
| `HomeMenuScene` の詳細 | 別途 `HomeMenuScene.md` で定義 |
| ミッション一覧画面のシーン名 | 後から命名する |
| `TabMenuController` の詳細 | 別途定義する可能性あり |
