# HomeMenuScene 企画・仕様概要（Planner / Game Designer 向け）

## 1. 概要

| 項目 | 内容 |
|---|---|
| シーン名 | `HomeMenuScene` |
| 役割 | `HomeScene` から開くメニュー画面 |
| 読み込み方式 | `SystemScene` 上に Additive で重ねて表示 |
| 閉じ方 | 左上の戻るボタンのみ（背景オーバーレイタップでは閉じない） |
| 演出 | オープン・クローズ時のアニメーションはなし |

## 2. UI構成

| 位置 | 要素 | 機能 |
|---|---|---|
| 左上 | 戻るアイコン＋「メニュー」テキスト | `HomeMenuScene` を閉じる |
| 中央上 | `ゲーム設定` ボタン | `BattleSettingScene` を Additive で表示 |
| 中央 | `タイトルへ戻る` ボタン | タイトル画面への遷移確認ポップアップを表示 |
| 中央下 | `アイテム` ボタン | `ItemScene` を Additive で表示 |
| 全画面 | 背景オーバーレイ | `HomeScene` の操作を受け付けない |

## 3. 機能・遷移フロー

### 3.1 ゲーム設定

- `ゲーム設定` ボタンをタップすると `BattleSettingScene` を Additive で読み込む。
- `HomeMenuScene` は閉じない。
- `BattleSettingScene` は戻るボタンのみで閉じる。

### 3.2 タイトルへ戻る

- `タイトルへ戻る` ボタンをタップすると確認ポップアップを表示する。
- ポップアップ内容：
  - メッセージ：`タイトルに戻りますか？`
  - 注意書き：`※セーブしていないデータは消えてしまいます。`
  - ボタン：`いいえ` / `はい`
- `いいえ` → ポップアップを閉じて `HomeMenuScene` に戻る。
- `はい` → `HomeMenuScene` を閉じ、`HomeScene` 経由で `StartScene` へ遷移する。

### 3.3 アイテム

- `アイテム` ボタンをタップすると `ItemScene` を Additive で読み込む。
- `HomeMenuScene` は閉じない。
- `ItemScene` は戻るボタンのみで閉じる。

## 4. サウンド

| 項目 | 内容 |
|---|---|
| BGM | `HomeMenuScene` では制御しない（`AudioManager` 管理） |
| SE | ボタンタップ時に `SE_Click` を使用 |
| ボイス | なし |

## 5. 入力制御

- Unity UI の `Button` コンポーネントを使用。
- 背景オーバーレイは操作ブロック専用。タップしても `HomeMenuScene` は閉じない。

## 6. 備考

- `HomeMenuScene` を閉じても `HomeScene` はアンロードしない。
- 各ボタンは六角形の見た目（Image コンポーネントで実現）。
- ゲーム設定・タイトルへ戻る・アイテム以外のメニュー項目は現時点で追加予定なし。

## 7. 今後検討事項

- 現時点ではなし。
